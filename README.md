# Autosfactory

A local board that takes Jira tickets assigned to me, hands them to coding agents (Claude plans, Antigravity implements), and tracks each ticket on a kanban board with a mandatory review before every pull request.

The plan is to build it on a clone of [Orca](https://github.com/stablyai/orca) (MIT license).

## Where things are

- `docs/wayfinder-map.md`: the planning map with every decision made. The same 9 planning tickets are in the Issues tab.
- `docs/build-plan.md`: the order to build in, in phases.
